# 🌙 Luna Runtime

Luna est un assistant personnel IA construit progressivement selon une architecture modulaire.

## État actuel

Version :

```
v0.2.0-dev
```

Premier objectif :

- démarrage du runtime ;
- initialisation du kernel ;
- préparation de l'intégration IA.

## Lancement

```bash
python main.py
```

## Tests

```bash
pytest
```
## Démarrage de Luna

Le point d'entrée officiel du projet est :

```bash
python main.py
```

Les anciens fichiers de démarrage (`run.py` et `bootstrap.py`) sont conservés pour la transition mais ne doivent plus être utilisés pour lancer l'application.
